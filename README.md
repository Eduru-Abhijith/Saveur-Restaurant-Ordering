# Saveur: Smart Restaurant Ordering

A React and Vite frontend demo for browsing a restaurant menu, building an order, and reviewing an itemized bill.

## Run locally

```sh
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run lint` to check the source.

## Demo boundaries

Checkout is simulated in the browser. No payment is processed, orders are not sent to a restaurant, and order data is not persisted. Menu photography and web fonts load from external services and require an internet connection.
